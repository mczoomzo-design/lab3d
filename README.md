## ขึ้นเว็บด้วย GitHub Pages (ฟรี ประมาณ 5 นาที)

1. เข้า https://github.com แล้วเข้าสู่ระบบ (หรือสมัครใหม่)
2. กดปุ่ม **New** (repository ใหม่) → ตั้งชื่อ เช่น `computer-class` → เลือก **Public** → **Create repository**
3. กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, โฟลเดอร์ `assets`, `.nojekyll`, `README.md`) ไปวาง → **Commit changes**
4. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/computer-class/`
6. นำลิงก์ไปใส่ใน Google Classroom หรือทำ QR Code ติดหน้าห้อง

> ถ้าลากโฟลเดอร์ไม่ได้ ให้สร้างไฟล์ `assets/xxx` ด้วยปุ่ม **Add file → Create new file** แล้วพิมพ์ชื่อ `assets/style.css` (มี `/` จะสร้างโฟลเดอร์ให้อัตโนมัติ) แล้ววางเนื้อหา

## การแก้ไขเนื้อหา

- เนื้อหาทุกแผน (สาระสำคัญ หัวข้อ ตัวอย่าง Prompt AI ลิงก์) อยู่ใน `assets/data.js`
- เครื่องมือแบบโต้ตอบอยู่ใน `assets/tools.js` · หน้าเว็บอยู่ใน `assets/app.js` · สีและรูปแบบอยู่ใน `assets/style.css`
- แก้ไฟล์บน GitHub ได้โดยตรง (ไอคอนดินสอ ✏️) → Commit → เว็บอัปเดตเองใน 1–2 นาที

## หมายเหตุ

- ทำงานบนเบราว์เซอร์ทั้งหมด ไม่เก็บข้อมูลนักเรียน ไม่ต้องล็อกอิน ใช้ได้บนมือถือ
- เครื่องมือ Python (วิชาการเขียนโปรแกรม) โหลดตัวแปลภาษาครั้งแรกประมาณ 10 MB จาก jsDelivr — ควรใช้ Wi-Fi
- AI ที่แนะนำทั้งหมดใช้ได้ฟรี: Gemini, ChatGPT, Microsoft Copilot/Designer, Google Colab, Google Stitch, Canva for Education, Teachable Machine, CapCut

## แล็บสามมิติ (lab3d/)
สื่อการสอนโต้ตอบ 3 มิติครบ 60 แผน สร้างด้วย three.js (r170, MIT License) อยู่ในโฟลเดอร์ `lab3d/`
- เปิดตรง: `lab3d/index.html#m2-8` (รูปแบบ `#<รหัสวิชา>-<แผน>`: m2 m5 cm4 mm6 web6 prog6)
- หน้าแผนแต่ละหน้าของเว็บไซต์มีปุ่ม "สื่อ 3 มิติของแผนนี้"
- แก้ฉากได้ที่ `lab3d/scenes/<วิชา>.js` (แต่ละแผนมี idea + build(L)) ฟังก์ชันช่วยอยู่ใน `lab3d/engine.js`
- ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (GitHub Pages หรือ `python -m http.server`) เพราะใช้ ES modules
